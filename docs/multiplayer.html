Online Arena Needs a Server

GitHub Pages can host static files only. Your multiplayer mode depends on a Node.js + Socket.IO server (server.js), so it cannot run directly on GitHub Pages.

The solo mode is fully playable on GitHub Pages. For online multiplayer, deploy the server to a backend host (for example Render/Railway/Fly.io) and point the web client at that server.
